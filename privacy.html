プライバシーポリシー

yutai-shorts（以下「本ツール」）は、運営者本人が自分の YouTube チャンネルへ動画をアップロードするためだけに使う個人用ツールです。

取得する情報

Google アカウントの認証情報（YouTube Data API のアクセストークン）のみを取得します。

利用目的

運営者本人の YouTube チャンネルへの動画アップロードと、チャンネル情報の更新にのみ使用します。

保存と第三者提供

認証情報は運営者のコンピュータ内にのみ保存し、第三者へ提供・販売することはありません。

Google API の利用

本ツールによる Google API から受け取った情報の利用は、Google API Services User Data Policy（Limited Use 要件を含む）に従います。
